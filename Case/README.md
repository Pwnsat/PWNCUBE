# PWNCUBE 3D-printable case

| File | Purpose |
|---|---|
| `Base-Body_X2.3mf` | Base plate |
| `Wall-Body_X2.3mf` | Enclosure wall |
| `SingleWall-Body_X2.3mf` | Single-wall variant |
| `Poste-Body_X1.3mf` | Standoff post |
| `5_SensorBoard_x3.stl` | Sensor board mount |

`.3mf` files are slicer project files (Bambu Studio / PrusaSlicer-compatible); `.stl` is a plain mesh importable into any slicer.
